# Статус — окна и двери в Феодосии

Одностраничный адаптивный сайт компании. Работает без сборки и сторонних библиотек.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в папке проекта.

## Публикация

Сайт готов для GitHub Pages: источник — корень ветки `main`.
